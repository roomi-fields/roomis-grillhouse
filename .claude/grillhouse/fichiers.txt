# The frame's files: `npm run grillhouse:maj` copies them, as they are, into a project. A line
# ending with « / » covers every file under that directory. A line « - <path> » removes that path
# from a project, and `npm run new` leaves it out of a new one: a file the frame no longer places
# there, or one that serves Grillhouse alone. The frame's scripts arrive at their path in its
# package (packages/grillhouse/scripts/), without the package itself; its tests and their material stay in
# Grillhouse (packages/grillhouse/tests/); the example's tests go with the template of a project
# (templates/projet/) to a new project.
