# The frame's files: `npm run grillhouse:maj` copies them, as they are, into a project. A line
# ending with « / » covers every file under that directory. A line « - <path> » removes that path
# from a project, and `npm run new` leaves it out of a new one: a file the frame no longer places
# there, or one that serves Grillhouse alone. The frame's own tests and their material stay in
# Grillhouse, each named below; the example's tests (tests/unit/config.spec.ts, errors.spec.ts,
# types.spec.ts) go with the example application to a new project.
